# Трекер дефектов — QA 2026

Шаблон курса для вашего трекера дефектов на GitHub Issues.

1. Use this template → Create a new repository.
2. Имя репозитория — из условия задачи, видимость — **Private**.
3. Settings → Collaborators → пригласить ревьюера курса: логин — из условия задачи, буква в букву. Приглашение должно быть принято.
4. Issues → New issue → форма «Баг».

В форме бага — поля баг-репорта: шаги, ожидаемое, фактическое, окружение и улика; заголовок Issue — одной строкой, что сломалось и где.

Метки шаблон с собой не переносит: в новом репозитории — стандартные метки GitHub, метки Severity и Priority создайте сами, когда они понадобятся.
